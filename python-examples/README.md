# Python examples for every concept

One small, commented, runnable script per concept from the ToolNest learning
tracks (`/resources` and `/ai`). Each file opens with a comment block (what the
concept is, where it is used) and ends with the expected output.

Tracks: python-ai, maths-ai, numpy, matplotlib, pandas, scikit-learn,
machine-learning, neural-networks, nlp, reinforcement-learning,
computer-vision, speech-processing, generative-ai, agentic-ai,
building-with-claude, langchain-langgraph-rag, fraud-detection.

Run any file: `python python-examples/numpy/01-arrays-the-basics/01_start-0.py`
(NumPy/pandas/matplotlib tracks need `pip install numpy pandas matplotlib`).

Regenerate after editing a concept (from `tools/`): `node scripts/export-python.mjs [slug]`.
