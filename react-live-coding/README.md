# React Live Coding

Six small, independent React exercises for interview live-coding. Each file is one component with only the basics (no extra libraries).

| File | Task | Key ideas |
| --- | --- | --- |
| `src/1-TodoList.jsx` | Add, complete, delete tasks | `useState`, `map`, `filter` |
| `src/2-SearchFilter.jsx` | Filter users while typing | controlled input, derived data |
| `src/3-ApiFetch.jsx` | Fetch with loading and error states | `useEffect`, `async/await`, `try/catch` |
| `src/4-DebouncedSearch.jsx` | Fewer API calls while typing | `setTimeout` + cleanup |
| `src/5-Pagination.jsx` | Records page by page | `slice`, page maths |
| `src/6-ShoppingCart.jsx` | Add products, show total | array state, `reduce` |

## Run

```bash
cd react-live-coding
npm install
npm run dev
```

Or copy any single file into CodeSandbox / StackBlitz and render it with `<App />`.
