These are metric-compatible substitutes for Arial/Helvetica (Arimo), Times New
Roman (Tinos), and Courier New (Cousine), used by the existing-text patch
pipeline (see ../fontMatch.ts) to embed a real, fully-covered font program in
exported PDFs instead of relying on a PDF viewer's own "Helvetica" name
substitution — which varies by viewer/OS and is the source of visible font
mismatches between the editor's on-screen preview and other viewers.
